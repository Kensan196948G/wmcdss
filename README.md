# 🌊 WMCDSS — 現場のお天気・海のコンディション 判断サポートシステム

> **2026-08-12 判断**: 本プロジェクトは後継プロジェクト
> **Civil-Weather-Water-Decision（CWW-D）** へ統合します。
> 本リポジトリは GitHub（private）で履歴保全済み。新規開発・本番運用は CWW-D 側で
> 継続し、NOWPHAS 海象取り込み・鮮度ガード・評価文書は移植済み/移植中です。

> **WMCDSS**（ダブルエムシーディーエスエス）は、
> 「今日この現場で工事を進めてよいか？」を、お天気と海の状況から自動で見える化するツールです。
>
> 正式名称：Weather-Marine Construction Decision Support System
> （現場気象海象 自動集計・施工判断支援システム）

---

## 📌 このシステムは何をしてくれるの？

建設・土木の現場では、**風が強い／波が高い／雨がひどい** といった天候によって、
「作業を進めてよいか」「いったん止めるか」を毎日判断しなければなりません。

これまでは、担当者が毎朝、気象庁のサイトを見て、経験と勘で判断していました。
**WMCDSS は、その判断を自動でサポートします。**

- 🛰️ 気象庁（JMA）の **最新のお天気・波のデータを自動で取得**
- 📋 現場ごとにあらかじめ決めた **「これを超えたら危険」という基準（しきい値）** と照らし合わせ
- 🚦 **信号機のように 3 段階** で「進めてよいか」を表示

### 🚦 3 つの判定

| 表示 | 意味 | どんなとき |
| :--: | --- | --- |
| ⛏️ **着手可** | 作業を進めて大丈夫 | お天気・海の状況がすべて基準内 |
| ⚠️ **警戒** | 注意しながら作業 | 基準に近づいている項目がある |
| ⛔ **中止** | 作業を止めるべき | 危険な基準を超えている項目がある |

判断した内容は **すべて記録（履歴）として残る** ので、
「なぜこの日は中止にしたのか」を後から確認できます。

### 従来とのちがい

| こんな悩み | これまで | WMCDSS なら |
| --- | --- | --- |
| 🌤️ 天気データ集め | 毎朝、担当者が気象庁サイトを目視 | **10 分ごとに自動で取得** |
| 📏 中止の基準 | 現場ごとに口頭・経験則でバラバラ | **数値の基準で誰が見ても同じ判定** |
| 📝 判断の根拠 | 議事録やチャットに散らばる | **すべて履歴として自動で記録** |
| 📱 みんなへの共有 | 朝礼や電話で連絡 | **ブラウザでいつでも・どこでも確認** |

## 🖥️ 使い方（画面の紹介）

WMCDSS は **インターネットブラウザ（Chrome や Edge など）で開くだけ** で使えます。
アプリのインストールは不要です。パソコンでもタブレットでもスマホでも見られます。

### 🔗 MVP 確認用 URL（2026-08-15 公開）

- **MVP / Prototype**: https://wmcdss-mvp.mirai-dx-platform.com （Cloudflare Tunnel・デモデータ投入済み）
- **本番**: 文書方針どおり後継 CWW-D 側で継続（本リポジトリは履歴保全）

画面は **「現場担当者向け」** と **「本社管理者向け」** の 2 つのモードを切り替えられます。

### 🔐 認証・権限（2026-08-12 追加）

- ログイン: 一般ログイン（ローカルユーザー）または Microsoft 365（設定時）
- 権限: **現場（field）・本社（hq）・管理者（admin）** の3ロール
  - 現場登録・しきい値変更・ETL実行・監査ログ・AI設定は管理者のみ
  - レポート出力は本社以上
  - ロールは `WMCDSS_ROLE_USERS_RAW` でユーザーごとに設定（詳細は IT-STAFF.md）

### 🗺️ ダッシュボード（トップ画面）

最初に開く画面です。**日本全国の現場が地図上にピン** で表示され、
それぞれの現場が今「着手可・警戒・中止」のどれなのかが一目でわかります。

- 全国 → エリア（北海道〜沖縄）ごとにボタン 1 つで絞り込み・ズーム
- 画面上部に **「中止推奨」「注意」の現場が横並びで一覧表示**
- 今日を含む **週間天気予報（サンプル表示）** や、現場ごとの気温・風速もカードで確認
  ※ 予報APIは未接続のため、予報カードは固定サンプルです。施工判断には使用できません。

### 📋 現場の管理

| 画面 | できること |
| --- | --- |
| **現場一覧** | 登録された全現場をリストで確認。検索や状態での絞り込みも可能 |
| **現場登録** | 新しい現場を追加（場所・種類・基準などを設定） |
| **現場詳細** | 1 つの現場の詳しい状況を表示 |

### 🌤️ お天気・海のデータを見る

| 画面 | できること |
| --- | --- |
| **気象データ** | 気温・風速・降水量など、現在・時間ごと・一覧表で確認。風向きを示す「風配図」も表示 |
| **海象データ** | 波の高さ・周期・潮位など、海のコンディションを確認 |

### 🏗️ 作業ごとの判定

| 画面 | できること |
| --- | --- |
| **コンクリート打設** | コンクリートを流し込む作業に向いた状況かを判定 |
| **海上作業** | 海の上での作業（5 種類）について、波の高さなどから判定 |

### 📈 過去のデータ・分析

| 画面 | できること |
| --- | --- |
| **過去データ分析** | 現場ごと・年度ごとに、風・波・雨の傾向をグラフで確認 |
| **50 年確率波** | 設計の基準となる「50 年に一度クラスの波の高さ」を確認 |

### ⚙️ 管理・設定（本社管理者向け）

| 画面 | できること |
| --- | --- |
| **しきい値管理** | 「これを超えたら警戒／中止」という現場ごとの基準を設定・変更 |
| **データ取得状況** | 気象データが正しく自動取得できているかを確認 |
| **レポート出力** | 状況を資料（レポート）として書き出し |
| **監査ログ** | 「誰が・いつ・何を変更／判定したか」の記録を確認 |
| **設定** | 表示モード（現場／本社）や見た目の設定など |

> 💡 **ダークモード**（暗い背景）や **文字の詰め表示** など、見やすさの設定も可能です。
> 設定は次回開いたときも引き継がれます。

## 📡 収集しているデータについて

WMCDSS が表示・判定に使うデータは、**気象庁（JMA）が公開している公的なデータ** を
自動で取得したものです。個人情報や現場の機密情報を外部から集めることはありません。

### 🌤️ お天気のデータ（AMeDAS／アメダス）

**10 分ごと** に、各現場に対応する気象庁の観測所から自動取得します。

| 項目 | 内容 |
| --- | --- |
| 気温 | 現在の気温（℃） |
| 湿度 | 空気の湿り具合（%） |
| 気圧 | 大気の圧力（hPa） |
| 降水量 | 降った雨の量（mm） |
| 風速 | 風の強さ（m/s） |
| 最大瞬間風速 | 瞬間的に吹いた最も強い風（m/s） |
| 風向 | 風が吹いてくる方角 |
| 日照時間 | 日が照っていた時間（h） |

### 🌊 海のデータ（参考情報）

海に面した現場では、波の状況を自動取得します。
**注意: 2026-08-12 時点で JMA 波浪データの提供方式が変わり、従来 URL では
取得できません。現在は Open-Meteo（参考情報・施工判断には未使用）と
国土交通省 NOWPHAS への切替を計画しています。海象ベースの判定は
「データ欠測」として安全側（注意）になります。**

| 項目 | 内容 |
| --- | --- |
| 有義波高 | 代表的な波の高さ（m） |
| 波周期 | 波が繰り返す間隔（秒） |
| 波向 | 波が来る方角 |
| 潮位 | 海面の高さ（m） |
| 流速 | 海流の速さ（m/s） |
| 流向 | 海流の向き |

### 🗂️ システム内で管理するデータ

| 種類 | 内容 |
| --- | --- |
| 現場情報 | 現場の名前・場所（緯度経度）・種類（陸上／海上）・住所・備考など |
| しきい値 | 現場・作業ごとの「警戒／中止」の判定基準 |
| 監査ログ | 誰が・いつ・何を変更／判定したかの操作記録 |

### 📥 データの集め方・更新のタイミング

- お天気データ（アメダス）：**10 分ごと** に自動取得
- 海のデータ（波浪）：**1 時間ごと** に自動取得
- サーバが一時的に止まっていても、**復帰時に取りこぼし分を自動で取得** します
- 取得元・取得時刻もあわせて記録するため、**いつ・どこの値か** が後から確認できます

> ℹ️ より詳しいデータの保存形式（データベースの項目）は
> [技術リファレンス](docs/TECHNICAL.md#-データモデル収集データの格納先) に記載しています。

## ❓ よくある質問

**Q. データはどのくらい新しいですか？**
A. お天気は最短 10 分ごと、海のデータは 1 時間ごとに自動更新されます。

**Q. この判定だけで作業の可否を決めてよいですか？**
A. WMCDSS は **判断を支援するツール** です。最終的な判断は、現場の責任者が
実際の状況とあわせて行ってください。万一データが取得できていない場合は、
画面に **赤い警告帯** が表示され、その値を施工判断に使わないよう促します。

**Q. スマホでも使えますか？**
A. はい。ブラウザがあればパソコン・タブレット・スマホのいずれでも利用できます。

**Q. 判定の基準は変えられますか？**
A. 本社管理者向けの「しきい値管理」画面から、現場・作業ごとに変更できます。
